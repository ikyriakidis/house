# Split-Wing House

Concept design for a single-storey house on a 19 × 53 m plot (street on the south).

| Page | What it shows |
|---|---|
| `index.html` | Cover page with the key figures |
| `plan.html` | Interactive floor plan: rooms, zones, routes, pool views, sun and shadow, site plan |
| `3d.html` | Interactive 3D model (three.js): furniture, roof options, solar panels, sun presets |

All pages are static HTML with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Key figures

- Plot: 1,000 m² (19 m frontage × 53 m depth)
- Heated area: 209 m² including walls (≈184 m² net), garage 39 m²
- Pool: 9 × 4 m, 7 m north of the house
- Assumed 3 m side setbacks; confirm Δ, κάλυψη and σ.δ. with the engineer

This is a concept sketch for discussion, not a construction drawing.
